# TSSR V6.4 — Correctifs de l’éditeur

- Réglage de largeur des images visible dans la barre d’outils : ouvrir **Modifier**, cliquer sur une image, déplacer le curseur.
- Passage bleu marqué explicitement pour la fiche de révision, y compris lorsque plusieurs nuances de bleu sont utilisées.
- La publication reprend automatiquement après la connexion GitHub si aucun jeton n’était encore chargé dans cet onglet.
- **Enregistrer et publier** dans l’éditeur enregistre le document puis lance la publication dans la même action.

IMPORTANT : l’éditeur de cours doit être ouvert pour modifier les images. Les images Word collées depuis des formats non transférables doivent être importées séparément. Vérifier la publication et les contenus dans le navigateur avant de considérer la mise à jour validée. Sauvegarder `data/custom.json` avant remplacement.
