# V6.5 — Correctif ciblé éditeur

- Sélection d’image au clic, largeur par curseur **ou saisie numérique** (10–100 %), alignement conservé dans le HTML.
- Publication : sauvegarde le cours dans le même clic puis tente la publication sans imposer un second passage dans l’éditeur. En cas d’échec, le brouillon local reste disponible.
