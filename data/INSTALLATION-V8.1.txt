TSSR V8.1 — INSTALLATION

1. Sauvegarder votre dépôt et en particulier data/custom.json.
2. Copier les fichiers de ce ZIP dans le dossier local du dépôt GitHub en conservant data/custom.json déjà présent.
3. GitHub Desktop : Commit to main, puis Push origin.
4. Attendre la publication GitHub Pages, puis recharger avec Ctrl+F5.

IMPORTANT : data/custom.json est volontairement ABSENT de ce ZIP afin de ne pas écraser les cours existants. Ne pas supprimer ce fichier du dépôt.
Les résultats des QCM sont enregistrés localement dans le navigateur et non synchronisés sur GitHub.
La progression affichée sur l’accueil est un indicateur du nombre de modules contenant au moins un cours personnel, et non un taux de maîtrise.
