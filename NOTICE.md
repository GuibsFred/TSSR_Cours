# Notice d'utilisation — TSSR

## Cours et modules

Dans **Cours**, choisir un module puis un chapitre. Le bouton **✎ Renommer** sur la carte du module permet de changer son intitulé. Le bouton **✎ Modifier** sous une carte de chapitre permet de modifier son nom, son module, son sous-dossier, son ordre et son illustration (30 images intégrées). Les contenus de cours ne sont pas modifiés par ces réglages.

**Ajouter un cours** ouvre l'éditeur. **＋ Module** crée un nouveau module lors de l'ajout d'un premier cours. **Retirer** masque un chapitre, sans effacer son fichier source. **Cours masqués** permet de le restaurer.

Pour modifier le contenu, ouvrir le cours et cliquer sur **Modifier** ou **Rédiger mon cours**.

## QCM

Dans **QCM interactifs**, **Nouveau QCM** ajoute un questionnaire. Chaque QCM dispose des boutons **Modifier** et **Supprimer**. La suppression est confirmée avant publication. Les QCM intégrés à un cours restent indépendants du masquage de ce cours.

## Commandes

Dans **Commandes**, rechercher par nom, mot-clé ou description, puis filtrer par environnement ou catégorie. Ouvrir une fiche pour lire sa syntaxe, son exemple et copier les commandes. Ajouter, modifier, importer ou exporter depuis la barre d'actions.

## Enregistrement GitHub

Les modifications sont d'abord conservées localement. Le bouton **Enregistrer et publier sur GitHub** écrit dans `data/custom.json` si la connexion GitHub est configurée. Vérifier le message de confirmation avant de quitter la page. Un changement de fichiers du site (ZIP) nécessite toujours une mise en ligne sur GitHub ; la gestion du contenu se fait ensuite dans le navigateur.

## Sauvegarde et sécurité

Faire une copie de `data/custom.json` avant de remplacer le site. Ne jamais mettre son jeton GitHub dans les fichiers du dépôt. Les cours masqués ne sont pas physiquement effacés du ZIP.
