TSSR V53 — CLASSEMENT PARTAGÉ

1. Dans Supabase > SQL Editor, coller le contenu de SUPABASE_V53_A_EXECUTER.sql et cliquer Run. Cette étape est obligatoire pour Block Drop et Démineur.
2. Publier le site complet avec GitHub Desktop (Commit puis Push).
3. Sur le site GitHub Pages, Ctrl+F5, lancer Block Drop, terminer et enregistrer un NOUVEAU score.
4. Dans Supabase > Table Editor > arcade_scores, vérifier la ligne.
5. Ouvrir en navigation privée pour vérifier le Top 10 partagé.

La V53 corrige aussi les en-têtes d’authentification pour les clés sb_publishable, les messages d’erreur et le contraste des scores. Les règles et graphismes des jeux ne sont pas modifiés.
Les scores locaux précédents ne sont pas importés automatiquement.
