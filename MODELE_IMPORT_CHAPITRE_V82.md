## 2. Exemple

```bash
ps -ef
```

=== POINTS ESSENTIELS ===
- Un processus est un programme en cours d’exécution.
- Chaque processus possède un PID.
- Les signaux permettent d’agir sur un processus.

=== COMMANDES À RETENIR ===
- `ps -ef` — Afficher les processus.
- `grep -i "motif" journal.log` — Rechercher sans distinguer la casse.
- `kill -15 PID` — Demander l’arrêt d’un processus.

La commande est cyan, les options marron et les arguments rouges.
