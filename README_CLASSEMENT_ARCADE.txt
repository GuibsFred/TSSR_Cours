CLASSEMENT ARCADE TSSR

Par défaut, scores conservés dans le navigateur.
Pour activer le classement partagé entre tous les visiteurs :
1. Créer un projet Supabase (supabase.com).
2. Exécuter ARCADE_CLASSEMENT_SUPABASE.sql dans SQL Editor.
3. Ouvrir assets/arcade-config.js et renseigner Project URL et anon/publishable key.
4. Publier les fichiers sur GitHub Pages. Ne jamais placer une clé service_role dans le site.

Attention : les scores sont déclaratifs côté navigateur et peuvent être falsifiés. Une protection robuste contre la triche exige une validation serveur.
