# Terminal Ops V3.4 — sept cartes de jeu distinctes

Base : TSSR_Cours-main (7)(1).zip (correction Claude), sans remplacer le site original.

- Les sept CARTES sont des environnements distincts, pas sept bâtiments d’un seul niveau.
- Palier 1 : agence (1-10) ; 2 : PME (11-25) ; 3 : datacenter (26-40) ; 4 : hôpital (41-60) ; 5 : multisite (61-75) ; 6 : infrastructure critique (76-90) ; 7 : centre de crise (91-100).
- Sept illustrations architecturales HD distinctes, et boutons permettant de les prévisualiser.
- Des zones de chaque carte avec services, équipements, connexion Wi-Fi ou Ethernet et fiche d'inspection.
- Aucune nouvelle ligne réseau n'est dessinée sur les illustrations : infos à la demande.
- Le bouton « Carte du niveau » revient à l'environnement correspondant au scénario actif.
- Les scénarios existants sont toujours six missions de démonstration, réparties sur les premiers niveaux, utilisant les interpréteurs simulés de la version source.
- Le reste des 300 niveaux est une feuille de route, PAS 300 missions déjà développées.
- Visuels 2,5D : ces illustrations ne sont pas des scènes 3D temps réel ni des modèles 3D navigables.
- Certaines étiquettes présentes dans les images d'illustration sont fixes : seules les zones de la liste interactive reflètent le scénario actif.
