# TERMINAL OPS V3.7 — Localisation et machines

- Carte affichée entière avec `object-fit: contain`, zoom 100–150 %.
- Bouton **Explorer les zones**, menu léger sans labels supplémentaires sur l’image.
- Fiches de zone et équipements disponibles avec IP, rôle, liaison Wi-Fi/Ethernet.
- **Se connecter** sur une machine change l’identité affichée dans le terminal.
- Une mission ne se résout que depuis sa machine cible; la session démarre sur TECH-01 et le joueur doit chercher la machine appropriée.
- La simulation reste pédagogique et partielle : les autres machines ne disposent pas encore d’un interpréteur complet indépendant. Leurs commandes de consultation de base fonctionnent, tandis que les interventions sont réservées à la cible du scénario.
- L’accès à une machine est simplifié : authentification et permissions distantes non encore modélisées.
