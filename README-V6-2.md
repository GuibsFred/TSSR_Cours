# V6.2 — Édition des images

Dans un cours, cliquez sur une image pour afficher les commandes de taille (10–100 %) et alignement gauche/centre/droite. La largeur est conservée à l’enregistrement et après publication GitHub. Les images déjà présentes sont également sélectionnables.

Le bouton de menu ☰ reste inchangé dans cette version.

Attention : tester l’éditeur et la publication avec une copie de vos données avant de remplacer le site.
