# TSSR Horizon Premium — V7.0 (candidate de test)

Base : archive du dépôt V6.6 fournie par l’utilisateur.

## Changements
- Chapitres ENI préparés à partir des intitulés visibles sur les photos du programme. Les modules sans détail confirmé restent vides et modifiables.
- Navigation et cartes de chapitres par module.
- Cours, fiche de révision et QCM possibles pour chaque chapitre.
- Import de QCM par copier-coller (A/B/C/D, Réponse, Explication), et ancien format à barres verticales.
- Bouton « Enregistrer et publier sur GitHub » pour Cheatsheets, commandes et QCM.

## Précautions
Sauvegarder data/custom.json avant installation. Les chapitres sont des entrées virtuelles, enregistrées dans data/custom.json uniquement après leur première modification.
La publication GitHub utilise toujours un jeton à accès limité et la limite de taille de l’API Contents s’applique aux images intégrées.
La syntaxe est contrôlée, mais les interactions n’ont pas été testées en navigateur réel.
